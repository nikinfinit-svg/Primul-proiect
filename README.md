# 🧤 Portar Handbal

Mini aplicație web pentru portarii de handbal. Este un singur fișier (`index.html`) și nu are nevoie de instalări: îl deschizi în browser, pe telefon sau pe calculator.

## Ce face

- **Meci**: notezi fiecare aruncare, adică poziția de unde s-a aruncat (extremă, 6 m, 9 m, 7 m, contraatac), zona porții (grilă 3×3) și dacă a fost paradă sau gol. Procentul de parade se vede live.
- **Istoric**: meciurile salvate, procentul total, o hartă a porții (verde înseamnă că aperi bine acolo, roșu că primești goluri) și statistici pe poziții.
- **Reflexe**: zonele porții se aprind la întâmplare și le atingi cât mai repede. Sunt 10 runde, iar aplicația ține minte recordul tău.

Datele se salvează local în browser (localStorage).
