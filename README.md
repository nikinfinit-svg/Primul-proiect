# 🧤 Portar Handbal

Mini aplicație web pentru portarii de handbal. Este un singur fișier (`index.html`) și nu are nevoie de instalări: îl deschizi în browser, pe telefon sau pe calculator.

## Ce face

- Adaugi jucătorii adversari, cu numele și postul fiecăruia (extremă, inter, centru, pivot).
- Fiecare jucător are poarta lui electronică. Apeși pe zona unde a aruncat, iar zonele se colorează:
  - 🔴 **roșu**: aruncă cel mai des acolo;
  - 🟡 **galben**: aruncă des;
  - 🟢 **verde**: aruncă rar.
- Primești sfaturi despre **cum să stai în poartă**, în funcție de postul jucătorului și de zonele unde aruncă.

Datele se salvează local în browser (localStorage).
